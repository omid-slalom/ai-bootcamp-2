# Functional Requirements

Core functional requirements for the ToDo app.

## FR-1: Item Management
- Items can be added.
- Items can be edited.
- Items can be deleted.

## FR-2: Item Ordering
- Items are listed in the order in which they were added.
- Deleting an item removes it without changing the relative order of the remaining items.

## FR-3: Timestamps
- Items are timestamped when they are added.
- Items are timestamped again when they are edited.

## FR-4: Notifications
- Every user action or event (e.g. add, edit, delete) sends a toast notification to the user.
